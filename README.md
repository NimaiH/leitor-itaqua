# Leitor-Itaqua 📚

### Projeto Integrador (PI) - UNIVESP
**Foco:** Biblioteca Municipal Prof. Aroldo de Azevedo (Itaquaquecetuba/SP)

O **Leitor-Itaqua** é uma plataforma web desenvolvida para modernizar a interação dos moradores de Itaquaquecetuba com o acervo da biblioteca municipal. O sistema vai além de um simples catálogo, integrando funcionalidades de rede social literária e gamificação para incentivar o hábito da leitura na comunidade.

## 🚀 Funcionalidades Principais

- **Acervo Público Digital:** Consulta em tempo real de livros disponíveis e em circulação (emprestados/manutenção), facilitando o planejamento do usuário.
- **Rede Social e Resenhas:** Espaço para usuários compartilharem opiniões sobre suas leituras com um sistema de formulário inteligente.
- **Gamificação (Sistema de Ranks):** Ganho de XP baseado em páginas lidas, com patentes que evoluem de "Iniciante" a "Mestre da Biblioteca".
- **Integração com API Google Books:** Busca automatizada de capas e informações para novos cadastros de livros.
- **Painel Administrativo:** Gestão simplificada do acervo físico e moderação de títulos.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3.x
- **Framework Web:** Flask
- **Banco de Dados:** SQLite
- **Front-end:** Bootstrap 5, HTML5, CSS3
- **Integração:** Google Books API
- **Segurança:** Python-Dotenv

## 📂 Estrutura do Projeto (MVC)
O projeto segue o padrão de arquitetura MVC para garantir organização e facilidade de manutenção.
