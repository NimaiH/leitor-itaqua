Nossa Trajetória: Do Bosque ao Município

Este projeto nasceu da disciplina de Projeto Integrador da UNIVESP.

Iniciamos como o "Leitor do Bosque", focado em uma comunidade específica. Durante o desenvolvimento, percebemos o potencial de escala e adaptamos toda a infraestrutura para atender a Biblioteca Municipal Prof. Aroldo de Azevedo.

Tecnologias Utilizadas:
Python (Flask), SQLite, Bootstrap 5 e Integração com API REST.
